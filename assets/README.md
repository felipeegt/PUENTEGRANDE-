# Assets - Personajes (Characters)

Este directorio contiene los assets del juego de pelea estilo KOF.

## Estructura

```
assets/
├── sprites/          # Sprite sheets de los personajes
│   ├── garravas/
│   ├── garravas_boss/
│   ├── dual/
│   ├── chapo/
│   ├── sobrino/
│   ├── incinerador/
│   ├── stoker/
│   └── soldado_elemental/
├── characters/       # Retratos de personajes (selección)
├── backgrounds/      # Fondos de escenarios
└── sfx/              # Efectos de sonido
```
